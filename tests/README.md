# Автотесты SLDT

Инструмент разработчика. На работу приложения не влияет: Service Worker эту папку не кэширует, в интерфейсе она не используется.

- `app.test.js` — настоящий `../index.html` целиком в jsdom (с v6.5.36 — ещё полоска прогресса, LEVEL UP и шрифты по вычисленному стилю; с v6.6.0 — карточка статуса, полоса таймера, окно «СТАТУС»): реальные нажатия «+», суточный сброс через `forceFullResetAction()`, активация предметов через `performUseItem()`. Руны, свитки, Бремя, тексты эффектов и уведомлений, окно правил.
- `consumables.test.js` — сочетания расходников (с v6.5.34; стопка штрафов, возврат опыта, Искупление, Исправление — с v6.5.35, с подменёнными часами для настоящих разных дней Летописи): уровни Рун Защиты, две части усиленной руны и Руны Возврата, все 25 пар усилений опыта, баннер штрафа, Заморозка, Скрижаль, Осколки Предела, предупреждения в окне подтверждения.
- `veil.test.js` — Костяная бусина и Пелена покоя, дневные эффекты во время Пелены и Заморозки.
- `backup.test.js` — бэкап (подписанный код и файл), Длань, Архив, уведомления в оформлении Системы, выбор темы.
- `theme.test.js` — тема «Система» (с v7.0.0): разметка окон и главного экрана, значок «!», красные схемы, возврат к «Классике», геометрия рамки, стили полос и Заморозки.
- `sw.test.js` — `../sw.js` в песочнице с имитацией `caches`/`fetch`: короткая установка, два кэша, network-first для страницы, офлайн, фоновая докачка.

Запуск (нужен Node.js 18+):

```
cd tests
npm install
npm test
```

Темы (с v7.0.0): `app.test.js`, `consumables.test.js`, `veil.test.js`, `backup.test.js` проверяют механику в классической разметке — при запуске переводят приложение в «Классику». `consumables.test.js` и `veil.test.js` прогоняются ещё раз в теме «Система»: `node consumables.test.js --system`, `node veil.test.js --system` (то же — переменной `SL_THEME=system`). `theme.test.js` всегда работает в теме «Система». Рисование рамки в jsdom не проверяется (нет размеров и холста) — только снимками в настоящем браузере.

Наборы идут долго (`sw.test.js` — около 2,5 минут); при ограничении времени запускать по одному.

Правило проекта: весь набор прогоняется перед сдачей каждой версии; новые механики добавляют сюда свои сценарии.
