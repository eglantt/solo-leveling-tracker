ПРОБА ОКОШКА

Страница без демо и без приложения: только сигнал и окошко. Шаги: 1) «Включить сигнал» — разрешить местоположение; 2) «Открыть окошко» — Chrome должен сжаться в маленькое окно; 3) перейти в другое приложение на 1–2 минуты; 4) вернуться и нажать «Скопировать отчёт». Если окошко не открывается — попробовать «Видео на весь экран», затем кнопку «Домой» телефона (Chrome может сам перевести полноэкранное видео в окошко).
