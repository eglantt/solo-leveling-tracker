# Solo Leveling: Daily Training

**Текущая версия: v5.9.43**

Трекер ежедневных тренировок в стилистике манхвы/аниме **Solo Leveling**. Ежедневное задание — полный норматив из пяти упражнений; неисполнение хотя бы одного из них влечёт штраф. Оформлено как «Система» из первоисточника — уровни, ранги, титулы, артефакты, предметы.

Никаких серверов, аккаунтов и трекинга — всё приложение работает полностью локально, в вашем браузере.

## Возможности

**Ежедневные задания**
Пять упражнений (отжимания, приседания, подтягивания, пресс, шаги) с целями, которые растут вместе с уровнем. На уровнях 1–10 цели ниже, чем на поздних. Задание по-прежнему ежедневное и полное: неисполнение любого из пяти пунктов влечёт штраф.

**Прокачка**
Уровни, ранги (от E до Shadow Monarch), характеристики (Сила / Ловкость / Выносливость / Интеллект / Восприятие), титулы за особые достижения.

**Штрафы и дисциплина**
Невыполнение задания снижает накопленный опыт. Тяжесть штрафа зависит от уровня и Силы — но полностью не исчезает никогда, оставаясь настоящим стимулом не пропускать дни. Если накопленного опыта не хватает для покрытия штрафа — недостача становится долгом, который отрабатывается будущим прогрессом.

**Преодоление предела**
После выполнения дневного задания можно превысить норму сверху, получая удвоенное вознаграждение — раз в сутки. Артефакты и расходники позволяют использовать эту возможность чаще.

**Предметы и артефакты**
- 8 постоянных артефактов с пассивными бонусами
- Расходники из Магазина Системы (руны, зелья, кристаллы, скрижали)
- 9 шкатулок разного тира со случайным лутом — большинство выпадает за левел-апы, отдельная непредсказуемая шкатулка может принести как награду, так и временное усложнение задания
- Цветные ключи для открытия редких шкатулок
- Уникальные предметы, доступные только из шкатулок

**Летопись**
Календарь с историей каждого дня — выполнено, оштрафовано или под защитой, с рекордом самой длинной серии.

**Прогресс**
Суммарная статистика по каждому упражнению за всё время, с возможностью посмотреть и по отдельным месяцам.

**Кодекс Системы**
Растущий справочник механик игры — новые главы открываются по мере прогресса, в индивидуальном для каждого игрока порядке.

**Звук**
Звуковые сигналы Системы на ключевые события — левел-ап, штраф, находки и другое. Включается и отключается в Архиве.

**Первый запуск**
При первом открытии Система сообщает условия задания — их можно пересмотреть в любой момент через Архив.

**Архив**
Экспорт и импорт прогресса (файлом или кодом), смена имени игрока, включение/отключение звука, повторный просмотр правил, полный сброс данных.

## Технологии

Один файл `index.html` — без сборщиков, фреймворков и зависимостей. Progressive Web App: устанавливается на телефон или компьютер, работает офлайн после первой загрузки (через Service Worker). Все данные хранятся локально в `localStorage` браузера.

## Установка

1. Откройте `index.html` через GitHub Pages (или любой статический хостинг).
2. На телефоне — «Добавить на главный экран» в меню браузера, чтобы получить отдельный значок как у обычного приложения.
3. На компьютере — иконка установки появится в адресной строке браузера (Chrome/Edge).

## Структура репозитория

```
index.html       — всё приложение целиком (разметка, стили, логика)
manifest.json    — манифест PWA
sw.js            — Service Worker (офлайн-кэш)
icons/           — иконки приложения и предметов
```
