# Solo Leveling: Daily Training

Локальный трекер ежедневных тренировок в визуальной стилистике манхвы/аниме **Solo Leveling**.

Это **фитнес-трекер с игровой оболочкой**, а не игра: никаких подземелий, врат и боёв — только реальные упражнения с прогрессией уровней, рангов, титулов, артефактов и предметов в духе «Системы» из первоисточника.

Никаких серверов, аккаунтов и аналитики. Всё работает в браузере, данные хранятся только на вашем устройстве.

## Дисклеймер

Неофициальный фан-проект. **Не аффилирован** с авторами, издателями или правообладателями Solo Leveling / Solo Leveling (나 혼자만 레벨업), D&C Media, Kakao, A-1 Pictures и связанными сторонами.

Названия, образы и сеттинг первоисточника принадлежат их владельцам. Этот репозиторий — личная тренировочная утилита с визуальной отсылкой к сеттингу.

## Возможности

**Ежедневные задания**  
Пять упражнений (отжимания, приседания, подтягивания, пресс, пробежка/шаги). Цели растут с уровнем; на 1–10 уровне — щадящая кривая.

**Прокачка**  
Уровни, ранги (от E до Shadow Monarch), пять характеристик (Сила, Ловкость, Выносливость, Интеллект, Восприятие), титулы за особые достижения.

**Штрафы и дисциплина**  
Пропуск дня снижает накопленный опыт. Тяжесть зависит от уровня и Силы, но полностью не исчезает.

**Преодоление предела**  
После выполнения дневного задания можно продолжить сверх плана и получить удвоенные кредиты — ограниченное число раз в сутки.

**Предметы**  
- 8 постоянных артефактов  
- расходники в Лавке Системы (руны, зелья, кристаллы)  
- 8 шкатулок разного тира  
- ключи для редких шкатулок  
- уникальные расходники только из шкатулок  

**Летопись**  
Календарь дней: выполнено / штраф / защита, рекорд серии.

**Кодекс Системы**  
Справочник механик; главы открываются по прогрессу.

**Архив**  
Экспорт и импорт прогресса (файл или код), смена имени, полный сброс. Рекомендуется периодически сохранять бэкап.

## Технологии

Один `index.html` — без сборщиков, фреймворков и npm-зависимостей.  
PWA: можно установить на телефон или компьютер, после первой загрузки работает офлайн (Service Worker).  
Данные — в `localStorage` браузера.

## Установка

1. Откройте приложение через GitHub Pages или любой статический хостинг (либо локально откройте `index.html`).
2. **Телефон:** в меню браузера — «Добавить на главный экран».
3. **Компьютер (Chrome/Edge):** иконка установки в адресной строке.

Сброс кэша при обновлении: если видите старую версию, обновите страницу с очисткой кэша или переустановите PWA.

## Структура репозитория

